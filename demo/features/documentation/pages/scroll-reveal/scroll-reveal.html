Importe ScrollReveal desde machetico-ui y declárelo en providers de su componente. Es un servicio local: cada vista posee sus observaciones y Angular las libera con DestroyRef. No lo convierta en un singleton global.

observe(element, onReveal)

Observa una entrada al viewport y devuelve cancelación idempotente. Agrega data-reveal=pending hasta poder mostrar el elemento; al revelar o cancelar lo deja visible. Al cancelar no ejecuta onReveal. Se usa también dentro de la directiva Reveal: no hay un segundo motor de observación.

enter(event, column?, options?)

Adapta animate.enter. El callback se completa una vez al finalizar, cancelar o fallar la animación. options.keyframes define la identidad; sin frames solo cambia el estado semántico. duration usa 320 ms por defecto; stagger usa 45 ms en tres posiciones; easing conserva el valor de Taurus y puede sobrescribirse.

leave(event)

Finaliza la entrada pendiente del elemento, libera su observación y completa el callback de salida. finished es una señal que indica si alguna entrada de esta instancia ya terminó; no representa el estado individual de todas las tarjetas.

El contenido inicial se mantiene visible en SSR. El navegador observa después del render; sin IntersectionObserver, sin Web Animations o con movimiento reducido, completa sin animación. Focus y beforeprint fuerzan visibilidad para no ocultar contenido utilizable. Mantenga además reglas CSS focus-within, impresión y prefers-reduced-motion para los estados pendientes.

Para una entrada sencilla con CSS puede usar la directiva Reveal. Para callbacks animate.enter y keyframes explícitos use este servicio.
