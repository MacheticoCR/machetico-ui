Comandos explícitos sin reintentos automáticos

Un path undefined cancela una lectura. request acepta AbortSignal; destruir el injector cancela comandos pendientes. ApiError conserva status y cuerpo del fallo HTTP; errores de parser, red y cancelación se propagan al propietario.

Las lecturas no transfieren respuestas al HTML. La aplicación debe decidir qué lecturas permite en SSR: transferCache false no evita por sí mismo que se envíe una solicitud de lectura. Los comandos se rechazan en el servidor antes de crear HTTP. No hay almacenamiento de credenciales, autorización de negocio ni caché de respuestas privadas completadas.
